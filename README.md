# JINX Website — Part 1

Navbar + animated hero, built from scratch with HTML, CSS and JavaScript.
Everything lives in a single `index.html` file — no frameworks, no build tools.

## Download
Click **`jinx-part1.zip`** → Download. Unzip and open `index.html` in your browser.

    jinx-part1/
      index.html
      img/

        lore-graffiti.jpg

## What's in it
- Responsive navbar with a working mobile menu
- Animated hero with particle canvas and custom cursor glow
- Pure CSS marquee and scroll indicator
