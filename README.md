# JINX Website

An animated, Arcane-inspired portfolio site built from scratch with HTML, CSS and JavaScript.
No frameworks, no build tools, no dependencies — just open `index.html` in a browser.

Built step by step on YouTube. Each part is a folder you can download and run.

## Parts

| Part | Sections | Folder |
|------|----------|--------|
| **Part 1** | Navbar + animated hero | `index.html` · `jinx-part1.zip` |
| **Part 2** | Lore section + arsenal cards | `jinx-part2/` |
| Part 3 | Pricing tiers + footer | *coming soon* |

## Download

**Part 1** — click `jinx-part1.zip` → Download → unzip → open `index.html`

**Part 2** — click the green **Code** button → **Download ZIP**, then open `jinx-part2/index.html`

## What's in it

**Part 1**
- Responsive navbar with a working mobile hamburger menu
- Animated hero with a particle canvas and custom cursor glow
- Pure CSS marquee and scroll indicator
- Glitch text effect on the title

**Part 2**
- Lore section with a CSS grid layout and graffiti photo frame
- Stat bars that animate on scroll using `IntersectionObserver`
- Arsenal grid — 6 cards with a 3D tilt that follows your mouse
- Fully responsive: 3 columns → 2 → 1
